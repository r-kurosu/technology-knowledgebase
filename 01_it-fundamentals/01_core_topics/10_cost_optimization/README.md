# コスト最適化

料金を単に下げるのではなく、必要な性能・可用性・安全性に対して無駄な支出を減らす。

## 全体の到達目標

- 構成の主要なコスト要因を特定できる
- 利用量、時間、データ転送、運用負荷を含めて比較できる
- 要件を壊さない改善案を説明できる
