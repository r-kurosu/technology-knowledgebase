# セキュリティ

誰が、何に、どの条件でアクセスできるかを制御し、データとシステムを保護するための基礎を学ぶ。

ここはIT基礎としての入門編。専門的な深掘りは [07_security](../../07_security/README.md) で行う。

## 学習する順番

1. [認証とアイデンティティ](01_authentication_and_identity.md)
2. [認可と最小権限](02_authorization_and_least_privilege.md)
3. [ネットワークとアプリケーション防御](03_network_and_application_security.md)
4. [暗号化と秘密情報管理](04_encryption_and_secrets.md)
5. [監査とガバナンス](05_audit_and_governance.md)

## 全体の到達目標

- 認証と認可を区別できる
- 最小権限と多層防御を設計できる
- 保存時・通信時の暗号化と鍵管理を説明できる
- 操作履歴を追跡し、問題を監査できる
