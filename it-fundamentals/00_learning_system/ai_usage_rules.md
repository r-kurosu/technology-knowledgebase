# AI利用ルール

## AIに任せてよいこと

- 概念説明のたたき台
- AWSサービス対応表
- Mermaid構成図
- 比較表
- よくある設計ミスの候補
- 理解確認用の質問の作成
- 自分が書いた説明文へのレビュー

## AIに任せないこと

- 一言説明の最終版
- 設計判断の最終版
- 30秒説明文
- ユースケースへの接続文
- 自分の弱点整理
- 理解確認への回答の最終版

## Claude Code / Codex に依頼するときのルール

- 対象ファイル、変更範囲、期待する出力を明示する
- AI生成可能なセクションと本人記入セクションを区別する
- 一次情報で確認すべき項目と、推測を区別させる
- 大きな変更は差分を確認してから採用する
- 既存ファイルの上書きや、依存関係の追加を伴う場合は事前確認を求める

## 自分が書くセクションの保護

「自分で書く」「AIは勝手に埋めない」と記載されたセクションは、明示的に依頼しない限り、AIに追記・置換・要約させない。

## 添削ルール

添削時は原則として本文を直接上書きせず、コメントまたは指摘形式で返してもらう。修正案は参考にし、最終版は自分で書く。

## 学習ページ作成時の禁止事項

- 本人記入セクションをAIが完成させること
- 出典未確認の内容を確定事項として扱うこと
- サービス名の羅列だけで理解したことにすること
- 要件や制約なしに単一の構成を正解として断定すること
- 過度に長いAI生成メモで、自分のアウトプットを埋もれさせること
- 実施していない検証や経験を、実績として記載すること
