# セキュリティ運用

防御は「作って終わり」ではない。侵害を前提に、どう検知し、どう対応するかを学ぶ。

## 扱う予定のトピック

- ログ設計と集約（何を、どこに、どれだけ残すか）
- SIEMと検知ルール（相関分析、アラート疲れへの対策）
- インシデントレスポンス（初動、封じ込め、根絶、復旧、事後レビュー）
- フォレンジック入門（証拠保全の考え方）
- 脆弱性管理の運用（パッチ適用の優先順位づけ、EPSS/KEVの活用）
- SOC/CSIRTの役割分担
