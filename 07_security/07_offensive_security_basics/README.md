# オフェンシブセキュリティ入門

読むだけでは攻撃者視点は身につかない。合法的な演習環境で手を動かし、防御設計に還元する。

## 扱う予定のトピック

- 演習環境の選択肢（CTF、TryHackMe、Hack The Box、OWASP Juice Shop）
- 脆弱性診断とペネトレーションテストの違い、実施時のルール（スコープ・許可）
- 基本ツールの理解（Burp Suite、nmap 等：何が見えるのかを知る）
- 学んだ攻撃手法を防御チェックリストに変換する習慣

## 注意

- 演習は必ず自分の環境か、明示的に許可されたプラットフォーム上でのみ行う
