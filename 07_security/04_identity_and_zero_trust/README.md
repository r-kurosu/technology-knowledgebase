# アイデンティティとゼロトラスト

「境界の内側は信頼する」モデルからの転換。アイデンティティを新しい境界として、認証・認可のプロトコルとゼロトラストアーキテクチャを深掘りする。

## 扱う予定のトピック

- OAuth 2.0 / OIDC の深掘り（フローの使い分け、トークンの検証）
- SAMLとエンタープライズSSO（IdP/SP、SCIMプロビジョニング）
- 多要素認証とパスキー（FIDO2/WebAuthn、フィッシング耐性）
- ゼロトラストアーキテクチャ（BeyondCorp、条件付きアクセス）
- マシン間認証（ワークロードアイデンティティ、mTLS、SPIFFE）
