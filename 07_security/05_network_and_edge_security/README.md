# ネットワーク・エッジセキュリティ

社内ネットワークとインターネットの境界が溶けた時代の、ネットワーク側の防御を学ぶ。ゼロトラストの概念（[04_identity_and_zero_trust](../04_identity_and_zero_trust/README.md)）を、ネットワークサービスとしてどう実装するかが中心テーマ。

## 扱う予定のトピック

- SASEの全体像（なぜ登場したか、SSEとの関係）
- SASEの構成要素（SWG、CASB、ZTNA、FWaaS、SD-WAN）
- VPNからZTNAへの移行（何が課題で、何が変わるのか）
- DNSセキュリティ（DNSフィルタリング、DoH/DoTの影響）
- DDoS対策とCDN（エッジでの防御、WAFとの役割分担)
- 代表的なプレイヤーの位置づけ（Zscaler、Netskope、Cloudflare等：カテゴリ理解のため）
