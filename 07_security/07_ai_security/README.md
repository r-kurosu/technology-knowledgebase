# AIセキュリティ

LLMをシステムに組み込む時代の、新しい攻撃面と防御を学ぶ。「AIを守る」と「AIで守る／攻める」の両面がある。

## 扱う予定のトピック

- プロンプトインジェクション（直接/間接、ツール呼び出し経由の攻撃）
- OWASP Top 10 for LLM Applications
- エージェント・MCPのセキュリティ（過剰な権限、ツールの信頼境界）
- データ面のリスク（学習データ汚染、機密情報の漏洩、出力のサニタイズ）
- ガードレールの設計（入出力フィルタ、人間の承認を挟むポイント）
- 攻撃側のAI活用（フィッシングの高度化、ディープフェイク）への備え
