# 脅威と攻撃手法

防御を設計する前に、攻撃者が「何を狙い、どう侵入し、どう広げるか」を知る。以降のすべての分野の前提になる、攻撃者視点の地図をつくる。

## 扱う予定のトピック

- 攻撃のライフサイクル（Cyber Kill Chain、MITRE ATT&CK の読み方）
- OWASP Top 10（Webアプリの代表的な脆弱性クラス）
- ランサムウェアと標的型攻撃の典型的な流れ
- フィッシング・ソーシャルエンジニアリング
- サプライチェーン攻撃（依存パッケージ、ビルド環境の侵害）
- 脆弱性情報の追い方（CVE、CVSS、JVN、EPSS）
