# Claude Certified Architect – Foundations (CCA-F) 試験概要

## 基本情報

| 項目 | 詳細 |
|------|------|
| 正式名称 | Claude Certified Architect – Foundations (CCA-F) |
| リリース日 | 2026年3月12日 |
| 提供元 | Anthropic |
| 対象者 | Claudeで本番システムを構築するソリューションアーキテクト |
| 受験資格 | Anthropic Claude Partner Network のパートナー企業社員（一般受験も可） |
| 受験料 | $99（パートナー企業の先着5,000名は無料） |

## 試験形式

| 項目 | 詳細 |
|------|------|
| 問題数 | 60問 |
| 形式 | シナリオベースの多肢選択式 |
| 試験時間 | 120分 |
| 合格スコア | 720 / 1,000 |
| 監督 | プロクター付き（オンライン） |
| シナリオ | 6つのシナリオコンテキストから4つがランダムに選出され、全問がそのシナリオに紐づく |

## 試験ドメイン（5領域）

| # | ドメイン | 配点比率 |
|---|---------|---------|
| 1 | **Agentic Architecture & Orchestration** | 27% |
| 2 | **Claude Code Configuration & Workflows** | 20% |
| 3 | **Prompt Engineering & Structured Output** | 20% |
| 4 | **Tool Design & MCP Integration** | 18% |
| 5 | **Context Management & Reliability** | 15% |

### Domain 1: Agentic Architecture & Orchestration（27%）
- マルチエージェントシステムの設計
- タスク分解の管理
- Hub-and-Spokeモデルによる複雑なワークフローの実装

### Domain 2: Claude Code Configuration & Workflows（20%）
- CLAUDE.md の階層構造の理解
- カスタムスラッシュコマンド
- CI/CDパイプラインへの統合

### Domain 3: Prompt Engineering & Structured Output（20%）
- JSONスキーマによる出力の信頼性確保
- Few-shotテクニック
- バリデーションとリトライループ

### Domain 4: Tool Design & MCP Integration（18%）
- Model Context Protocol (MCP) サーバーの設計
- ツール境界の管理（推論過負荷の防止）

### Domain 5: Context Management & Reliability（15%）
- ロングコンテキストの保持
- ハンドオフパターンの管理
- 信頼度キャリブレーション

## 今後の展開
- 2026年後半に追加の認定資格（Seller、Developer、Advanced Architect向け）がリリース予定
- CCA-Fは認定資格スタックのエントリーポイントとして位置づけ
