# CCA-F 学習スケジュール（4週間 / 約30時間）

> 目安: Claudeで日常的に構築している人で2〜4週間（20〜30時間）
> 推奨: 練習テストで900/1000以上を安定して取れてから本番を予約

---

## Week 1: 基礎知識の習得（8時間）

### Day 1-2: 試験概要の把握 & Anthropic Academy（3時間）
- [ ] 公式試験ガイドPDFを精読（12問サンプル + 4つの準備演習）
  - [Exam Guide PDF](https://everpath-course-content.s3-accelerate.amazonaws.com/instructor/8lsy243ftffjjy1cx9lm3o2bw/public/1773274827/Claude+Certified+Architect+%E2%80%93+Foundations+Certification+Exam+Guide.pdf)
- [ ] Anthropic Academy（Skilljar）から以下のコースを受講:
  - [Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol)
  - [MCP Advanced Topics](https://anthropic.skilljar.com/model-context-protocol-advanced-topics)
- [ ] `CCA-F_概要.md` を読んで試験構成を把握

### Day 3-4: Domain 1 — Agentic Architecture & Orchestration（3時間）
- [ ] `Domain1_Agentic_Architecture.md` を通読
- [ ] 必読: [Building Effective Agents](https://www.anthropic.com/research/building-effective-agents)（5つのワークフローパターン）
- [ ] 必読: [How We Built Our Multi-Agent Research System](https://www.anthropic.com/engineering/multi-agent-research-system)
- [ ] 必読: [Building Agents with the Claude Agent SDK](https://www.anthropic.com/engineering/building-agents-with-the-claude-agent-sdk)
- [ ] 5つのワークフローパターンを暗記（チェーニング、ルーティング、パラレル化、Orchestrator-Workers、Evaluator-Optimizer）
- [ ] stop_reasonによるループ制御を理解

### Day 5: Domain 2 — Claude Code Configuration & Workflows（2時間）
- [ ] `Domain2_Claude_Code_Workflows.md` を通読
- [ ] 必読: [How Claude remembers your project](https://code.claude.com/docs/en/memory)
- [ ] 必読: [Extend Claude with skills](https://code.claude.com/docs/en/skills)
- [ ] 必読: [Configure permissions](https://code.claude.com/docs/en/permissions)
- [ ] CLAUDE.md階層と設定ファイルの優先順位を暗記

## Week 4: 最終仕上げ & 本番（6時間）

### Day 16-17: フルサイズ模擬試験（3時間）
- [ ] 公式模擬試験（60問）を受験（登録後利用可能）
- [ ] タイマーを120分に設定して本番同様の環境で実施
- [ ] スコアが720未満の場合 → 弱点ドメインの補強を追加で実施

### Day 18-19: 最終復習（2時間）
- [ ] 全ドメインの「重要用語集」「チェックリスト」を最終確認
- [ ] 以下の最頻出項目を再確認:
  - stop_reasonによるループ制御
  - 5つのワークフローパターンの使い分け
  - CLAUDE.md階層と設定ファイルの優先順位
  - MCPの3プリミティブと制御モデル
  - 三層信頼性モデル
  - コンテキストエンジニアリングの5操作
  - エラー分類と対処法
  - tool_choiceの4つのオプション
- [ ] 試験当日の体験談を読む: [CertLand](https://certland.net/blog/cca-f-exam-day-experience-what-to-expect/)

### Day 20: 本番受験（1時間）
- [ ] 2.5時間ブロックをカレンダーに確保（120分 + バッファ）
- [ ] 静かな環境、安定したインターネット接続を確保
